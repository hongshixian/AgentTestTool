记录日期：2026-09-14

## 结论

在 385 条 CLI 宽松判定版 v3 母用例中，共有 **63 条**无法由仅掌握本地 CLI、普通测试账号和公开接口的第三方独立完成完整判定，占 **16.36%**。

这些用例统一标记为“需运营方材料/访谈/服务端证据”。在证据未提供前，测试脚本不执行 CodeBuddy CLI 代表路径，直接返回“不适用”，并在原因中列明所需证据。

“不适用”表示当前缺少运营方控制的判定依据，不表示产品不适用，也不表示产品满足或不满足对应要求。

## 使用边界

- 运营方口头承诺不能单独作为通过证据；访谈应形成可追溯记录，并与当前版本配置、日志或材料交叉核验。
- 本地 CLI trace 只能证明当前进程可观察的执行事件，不能证明云端留存周期、全量服务端覆盖或内部治理流程。
- 运营方提供证据后，应另行执行材料核验或服务端审计流程，不应由本地 CLI 测试脚本自动改判为通过。
- 当前母用例 ID、优先级、类别和历史代表子用例信息继续保留，用于来源追溯。
